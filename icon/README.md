# Gleanly logo ve marka dosyaları (`icon/`)

Tüm logo dosyaları bu klasörde. Kaynak görsel `source/gleanly-logo-acik-zemin.png` (2400×897, açık zeminli). Aşağıdaki dosyalar bu görselden renk ayrıştırmayla üretildi; vektör (SVG) sürümü yok. `source/gleanly-primary-oklu-halka.svg` farklı bir tasarım (oklu halka) olduğu için kullanılmaz, yalnızca saklanıyor.

| Dosya | Kullanım |
|---|---|
| `gleanly-logo.png` | Yatay logo, şeffaf zemin, açık arka plan için |
| `gleanly-logo-dark.png` | Yatay logo, şeffaf zemin, koyu arka plan için (yazı açık renk) |
| `gleanly-icon.png` | Yalnızca simge, 512×512, şeffaf, açık arka plan |
| `gleanly-icon-dark.png` | Yalnızca simge, 512×512, koyu arka plan için |
| `gleanly-icon-180.png` | Apple touch icon |
| `gleanly-icon-64.png`, `gleanly-icon-32.png` | Küçük simge boyutları |
| `favicon.ico` | 16, 32, 48, 64 px |

Slogan: **Circular Resource Intelligence**

## Notlar

- Simge 546 px genişlikteki kaynaktan çıkarıldığı için 512 px'ten büyük kullanılmamalı. Daha büyük baskı için vektör sürüm gerekir.
- Simgenin sağındaki ayrı kahverengi nokta logonun parçasıdır; kırpılmamalı.
- Küçük boyutlarda (32 px altı) noktalar birleşir; favicon'da simgenin tamamı yerine halka ve küme görünür kalır.
